Markdown File for _people/[slug].md

Create a new file _people/[slug].md with this content. All person data is included in the front matter - the website will automatically parse it!

Instructions:
  1. Click "Download .md File" to download the markdown file, or copy the content manually
  2. Save the downloaded file to _people/[slug].md (replace [slug] with the actual slug from the filename)
  3. Upload the person's photo to assets/img/people/ if you haven't already
  4. The person will automatically appear on the people page! No need to edit _data/people.yml - the website reads directly from the markdown file.
  5. Note: You may need to restart your Jekyll server for new files to appear.
