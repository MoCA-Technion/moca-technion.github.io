## Open positions
- **PhD / MSc students** (mobility modeling, computation, equilibrium, ML)

- **Visiting students / postdocs** (by arrangement)

If you're interested, please email **{{ site.data.site.email }}** with:

- Strong quantitative foundations (optimization, probability, ML, networks)
- Care about theory *and* implementation
- Clean writing and reproducible code
