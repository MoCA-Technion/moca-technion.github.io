# MoCA Lab Website

This repository contains the public website for the **Mobility Computation & Analytics (MoCA) Lab** at the Technion – Israel Institute of Technology.

The site presents our research, people, publications, projects, news, and ways to get in touch.

## Updating content via forms

On the live site you can create and update content using simple forms:

- **Add a person**: visit `/people/add-person/`, fill the form, then save the generated markdown file into the `_people/` folder.
- **Add news**: visit `/news/add-news/`, fill the form, then save the generated markdown file into the `_news/` folder.
- **Add a project**: visit `/projects/add-project/`, fill the form, then save the generated markdown file into the `_projects/` folder.
- **Update a project**: visit `/projects/update-project/`, select an existing project, update its details, then save the new markdown file over the old one in the `_projects/` folder.

After committing and pushing the markdown files, the site will automatically show the updated people, news, and projects.
